# 🐍 Hand-Controlled Snake Game (AI + OpenCV)

This is an interactive *Snake Game* built with *Python, **OpenCV, and **CVZone* where you control the snake using your *hand movements* through your webcam.  
It detects your hand in real-time and moves the snake accordingly — the goal is to eat the food and grow longer!

---

## 🎮 Features
- Real-time hand tracking using OpenCV and CVZone  
- Fun AI interaction with your webcam  
- Food increases snake length dynamically  
- Game Over screen with restart option  
- Funny sound effect when losing 😆  
- Smooth and responsive gameplay

---

## 🧠 Technologies Used
- *Python 3*
- *OpenCV*
- *CVZone*
- *Pygame* (for sound effects)
- *Math & Random* (for movement logic)
